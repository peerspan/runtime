# Contributing

Thank you for your interest in the runtime.

**Open an issue; please do not open a pull request.** We do not accept code contributions
from outside Peerspan. Pull requests from outside are closed automatically with a pointer
back here. This keeps all of the code under one authorship while the project is young.

Issues are where you can help:

- **Bug reports:** what you ran, what you expected, what happened, and your platform.
- **Feature requests:** the problem you are trying to solve, before any proposed solution.
- **Design feedback:** questions or objections about how the runtime works.

Describe changes in words rather than pasting patches. We read code in an issue only as a
description and write the change ourselves.

For security problems, do not open a public issue. Use GitHub's private vulnerability
reporting on this repository instead.
